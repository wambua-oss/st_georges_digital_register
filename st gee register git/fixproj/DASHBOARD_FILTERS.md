# Dashboard Grade and Stream Filters

- ECDE: PP1, PP2. No streams are offered.
- Primary: Grade 1–6. Streams: PE, PK, PL, PR, PS.
- JSS: Grade 7–9. Streams: JE, JK, JL, JR, JS.
- Selecting a grade with no stream displays the entire selected grade/class.
- Selecting a stream displays only that grade and stream.
- Whole School Attendance remains available from the dashboard.
